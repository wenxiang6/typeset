## 线上白屏修复：React #185 无限更新（2026-10-28 21:00）

**现象**：豆包用 skill 推了 5 页稿（第一期·超强厄尔尼诺），打开 9705 直接白屏，ErrorBoundary 报 `Minified React error #185`。

**根因（两条，都在自动测量闭环上）**
1. `reflowDoc` 对超页块执行 `el.h = g.height`（压成栏高），测量又量出真实高度写回，两者对拉永不收敛。实测 `quiz 641.4 ↔ 649`，641.4 正是栏高。
2. `Canvas` 的跨页切分没有次数上限。判定条件 `el.kind==='box' && variant!=='table' && variant!=='qr'` 把 quiz/note/tpl/trap 这些**带边框的容器**也当文字流按行切，切出碎框 + 续块，页数从 5 暴涨到 8。切完还装不下就无限切。

**修复**
- `Canvas.tsx`：新增 `SPLITTABLE_VARIANTS = new Set(['paragraph','subhead','req'])`，容器类一律整块挪页不切。
- `Canvas.tsx`：三道熔断 ref —— `splitTries`(3)、`heightTries`(6)、`measureRounds`(40 + 300ms 冷却)，超限放弃自动调整、`console.warn` 一次。
- `Canvas.tsx`：贴满栏底（`el.h >= geom.height - 0.5`）且要长高的块，直接不提高度，避免白跑。
- `layout.ts` `applyHeights`：同一条守卫（`next > el.h && el.h >= g.height - 0.5` 跳过），并把 `getGeometry` 提前、下面的重算改名 `gAfter`。

- 崩稿：5 页、65 组件、2776 字，**零丢失**，唯一日志是「该块内容比一栏还高 8px」。
