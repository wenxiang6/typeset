# 地理时政周刊 · 排版编辑器

React 19 + Vite + TypeScript 的报纸/周刊排版工具。默认入口是**可视化排版编辑器**，
支持双栏 A4 横版/竖版、53 种可搜索组件、拖动避让、文字自动增高、跨页按行切割、
溢出自动翻页、全屏背景图、本地图片和打印/导出 PDF。

```bash
pnpm install
pnpm dev          # http://127.0.0.1:5173
pnpm build        # 生成可直接双击的单文件版
pnpm typecheck
pnpm smoke        # Playwright 回归（32 项）
pnpm mcp          # 项目 MCP（stdio）
```

## 打开方式（白屏问题已修复）

| 方式 | 说明 |
| --- | --- |
| `pnpm dev` → `http://127.0.0.1:5173` | 开发模式，支持本地图片 `/@local` 代理 |
| 双击 `dist/地理周刊-排版编辑器.html` | 单文件 HTML：CSS/JS 全部内联；图片从同目录 `images/` 读取 |
| `pnpm preview` | 预览构建产物，同样支持本地图片代理 |

> 以前直接打开 `dist/index.html` 会白屏：Vite 默认用 `/assets/...` 绝对路径，
> 在 `file://` 下被浏览器 CORS 拦截。现在 `pnpm build` 会自动把 CSS/JS 内联成单文件 HTML（`dist/images/` 需与 HTML 同级保留）。
> 另外加了全局错误兜底：坏存档/运行期异常会显示恢复面板，而不是白屏。

## 核心排版能力

### 1. 拖动避让，不再“消失”

- 拖动的组件会临时置顶，不会被高层级的不透明块盖住。
- 被压住的组件沿拖动方向/最小穿透方向推开，可级联；被推到页底的组件会进入分页流程。
- 锁定元素是实心障碍，拖不进去。
- 被推动的组件始终限制在版心/自身区域内，不会飞到页头、页脚下面躲起来。

### 2. 跨页移动 + 自动补齐（紧凑布局）

- 直接把组件拖到其他页面上松手，即可跨页移动；拖到最后一页下方会新建一页。
- 跨页拖动时源组件半透明、指针旁显示浮层预览，目标页有橙色虚线框和「松手移到第 N 页」提示。
- 松手后**原页自动补齐**：每栏从版心顶部紧凑重排，元素之间只保留 4px 间距，不再留下大洞。
- 右侧属性面板也可「移到第 N 页」，或使用「← 上一页 / 下一页 →」「移到该页」。
- 锁定元素不参与补齐移动，作为固定障碍保留原位。

### 3. 自动高度 + 按行切割 + 自动翻页

- 正文/内容框按真实内容自动增高，下方组件依次下推。
- 超过页底的文字块会在**页底按整行切开**：
  - 上半段留在原组件；
  - 下半段生成一个新组件，接到下一栏/下一页；
  - 不会把一行字切成两半，也不会产生只有标点的小碎片（上下段至少 12 字）。
- 图片、分隔线等不可拆分的组件整块流动。

阅读顺序：

- 第 1 页的左栏、右栏都是初始设计内容；任意一栏溢出 → **第 2 页左栏**（右栏溢出不会进第 2 页右栏）。
- 第 2 页起：左栏溢出 → 本页右栏；右栏溢出 → 下一页左栏。
- 手动「下一页」也统一接到目标页左栏顶部。

### 4. 打印预览：彩色 / 黑白、无空白页

- 点工具栏打印按钮先打开「打印预览」：可选 **彩色预览 / 黑白预览**，再点「打开打印预览」。
- 预览是**应用内全屏 iframe**，不弹新窗口、不会被浏览器拦截；只包含 A4 纸张页面和打印工具栏。
- 在预览窗口里点「打印 / 保存 PDF」才会打开系统打印对话框。
- 黑白预览用 CSS grayscale 同时作用于屏幕画布和打印输出，不改变页数。
- 打印时自动隐藏工具栏、侧栏、选中框/控制点，但**关闭打印后编辑器的选中状态会保留**。
- 修复空白页：打印时把侧栏折叠按钮、画布内边距、非纸张宽度全部清零，并按 A4 宽度约束页面；回归会用 PDF 实际页数校验，3 页文档必须输出 3 页。

### 5. 表格与组件结构编辑

- 表格：新建为 **3×3 空白表**，不带示例内容，可一键「清空表格内容」。
- 右侧「表格结构」显示当前行×列，可改表头/单元格，直接 ＋行 / ＋列 / −行 / −列；新增行会**沿用上一行行高**。
- 选中表格后，表格内部会出现**列线 / 行线拖拽把手**：上下拖行线改行高，左右拖列线改相邻列宽，宽高随拖动实时更新。
- 其他复合组件（时间线、左右对比、卡片、徽章等）：选中后在「内部元素」里可改文字内容、复制、上移、下移、删除；结构变化后自动重排。
- **逻辑链**：专用节点编辑器，只填节点，节点之间自动生成 →；加节点自动补箭头，删节点自动收链。
- 任意组件底部的「HTML 源码 / 高级结构编辑」可以直接改内部 HTML，适合没有专用表单的组件。

### 6. 复合组件内部元素

- 选中报头、页眉、页脚、卡片等复合组件后，右侧出现「内部元素」列表，如报头的「期刊一 / 主标题 / 副标题」。
- 点列表项，或先在画布上选中组件、再点内部文字，即可单独选中该内部元素（橙色虚线框）。
- 可单独改字体、字号、字重、字色、对齐、斜体/下划线；也可用方向键 1px / Shift 10px 调位置。
- 内部元素变高时，外层组件框会自动长高；改完可点「重置此内部元素」。

### 7. 底色 / 背景色

- 「底色」就是组件背景色，作用到组件内容表面，不是只改外层透明选区。
- 提示框、表格、页脚、卡片等内容组件内部自带白底，之前会盖住外层颜色；现已改为直接给内容表面着色。
- 支持预设色、透明、原生取色器自定义颜色；当前色块带蓝色选中圈。

### 8. 组件识别 + 方向键微调

- 点选任意组件后，右侧属性栏标题显示组件中文名，例如「组件属性 · 正文」「组件属性 · 提示框」「组件属性 · 页脚」。
- 方向键移动 **1px**，Shift + 方向键移动 **10px**；
- 微调不会触发自动补齐/重排，组件不会刚移动就被吸回原位；需要重新紧凑时点「立即重排」。
- 页眉/报头/页脚仍受页边区域约束：整宽页脚左右已贴边时，横向不会再移动，但纵向可以微调。

### 9. 线宽统一可调

- 选中组件后，右侧「外观 / 层级 → 线宽」可设 1/2/3/4/6/8px 或恢复默认。
- 作用于：页眉下划线、报头装饰线、章节下划线、页脚上边框、提示框/概念框/逻辑链/模板边框、表格边线、卡片/对比/材料/公式/目录/批注/二维码边框、三种分隔线、区域虚线框。
- 「分隔线」组件的线宽 = 组件高度，可直接用 1/2/3/4/6/8 按钮调粗细。
- 编辑器内页脚已改为正常文档流：选择框与页脚内容完全一致，不再出现“框在上面、内容在下面”的错位。

### 10. 53 种组件 + 动态常用 + 列表模板

- 标题/导读、文本、内容框、数据/图表/版式/装饰、其他，共 53 种。
- 新增 **报头**：放在页眉下方，包含期刊名、主标题、副标题，可继续用「内部元素」单独调字体/位置。
- 新增 **有序列表 / 无序列表**：右侧「列表模板」可在圆点/方块/对勾/箭头/卡片、数字/前导零/字母/罗马/中文/括号/大号数字/带圈数字等模板间切换，并增删改列表项。
- 组件库「常用」区新增 **页眉 / 页脚**：页眉自动落在页顶，页脚自动落在页底并更新页码，可改内容/字号/线宽。
- 页眉/页脚的**内容、字体、线宽、尺寸、内部元素、位置**在任意一页修改后会同步到所有页；页脚页码仍按页自动更新。
- 新增：副标题、三级标题、编号标题、英文小标、导语、金句、数据强调、图注、署名；
  选择器组、材料分析、知识卡片、考点清单、三种提示条；数据卡片、左右对比、时间线、表格、公式；
  本期导读、编者按、页边批注、二维码框、标签徽章、色块标题条、序号圆标、三种分隔线。
- **常用区是动态的**：不再预置固定清单；你实际点击/拖入过哪个组件，它就自动 push 到「常用」最前面；已经在常用里的组件保持原位置，不会重复 push。
- 常用最多 **12 个**：超过时踢掉最后一个，再 push 新的。记录保存在 localStorage。
- 画布选中某个组件时，组件库里对应的组件会高亮；项目里出现的任何变体都能在组件库找到对应项。
- 网格排列，默认每行 **4 个**，可在组件库右上角切换 **4 / 5 栏**；长名称使用短名 + 悬浮完整说明。
- 组件库顶部搜索框支持按名称/说明过滤。

### 11. 二维码框可更换图片

- 选中二维码框，右侧「二维码图片」可填 URL / `file://` / data URL，或点「选择二维码图片」上传本地图片。
- 二维码会渲染成真实 `<img>`，打印时不会因“背景图形”选项被漏掉。
- 右侧「扫码关注…」文字可双击组件直接改。

### 12. 模板库（本地优先）

- 内置「默认模板 · 现有布局」作为第一个模板，可直接复用。
- 「保存当前布局为模板」保存到 localStorage；模板包含页面、组件、图片（尽量内嵌为 data URL）。
- 模板卡片支持应用、分享、删除；分享下载 `.paiban.json` 文件，别人用「导入模板文件」即可使用。
- 所有模板、当前文档都存本机，不需要服务器；后续打包本地 App 时可直接沿用。

### 13. 玻璃态 UI

- 侧栏、格式栏、属性面板、打印浮层统一使用半透明玻璃态 + 背景模糊 + 圆角 + 柔和阴影。
- 画布使用柔和渐变背景，纸张圆角显示（打印时恢复直角）。
- 按钮、输入框、组件卡片、颜色块统一圆角和 hover 反馈。

### 14. A4 横版 / 竖版

- 工具栏「竖版 / 横版」或右侧「页面设置」一键切换，所有页统一方向。
- A4 物理尺寸按 96dpi 精确换算（297×210mm / 210×297mm）；版心固定：左右 12mm、页眉 10mm、页脚距底 16mm。
- 切换时重算双栏宽度，组件按栏重映射；文字重新测量、下推、翻页。
- 页眉 / 报头 / 页脚是页面固定件，移动范围限制在页边区域，不会改变正文版心，也不会把整页内容挤走。
- 页眉/报头也参与真实高度测量：字号变大时框会跟着长高，正文起点同步下移，不会出现“框小内容大”压住下方组件。
- 回归测试会同时检查“页眉/报头/页脚与正文重叠”和“组件框高度小于内容高度”。
- 如果旧存档已经被误拖成空白第一页，读取时会自动检测并重建分页；也可在右侧页面设置点「重建分页 / 修复空白页」。
- 页脚页码自动更新为「当前页 / 总页数」。
- 打印 `@page` 尺寸跟随当前方向。

### 15. 全屏背景图

- 组件库「其他 → 全屏背景」：铺满所有页、自动置底（`z = -100`）、不参与避让/分页。
- 新页自动继承背景；切换横竖版自动铺满新纸张。
- 选中图片后可在右侧「设为全屏背景」「应用到所有页」。
- 背景图也可以用透明度滑杆压暗，方便正文阅读。

### 16. 本地图片

- `public/images/` 里的图片：`/images/img1.png`（默认示意图已放入）。
- 网络图片：`https://...`。
- 本机图片：
  - 开发/预览：`file:///Users/xxx/img1.png` 或 `/Users/xxx/img1.png`，走 `/@local` 代理；
  - 单文件版（`file://`）：使用 `file://` 或相对路径直接读取；
  - 通过 http 打开时，本地路径无法被浏览器直接读取，推荐用「选择本地图片」内嵌成 data URL。

## 编辑器用法

- **改字**：双击文本块进入行内编辑；点空白/Esc 提交。
- **移动/缩放**：拖动移动，可拖到其他页/新页；8 个角点缩放；方向键微调（Shift ×5）。
- **加组件**：左侧拖入或点击；新组件自动对齐左/右栏，重叠内容下推。
- **区域约束**：画布工具条「▭ 框选区域」；区域内元素拖动/缩放被钳制。
- **格式栏**：字体、字号、加粗/斜体/下划线/删除线、字色、高亮、对齐、行距、字距、列表。
- **页面**：新增/删除页、上一页/下一页、立即重排/修复版面。
- **存取**：自动存 localStorage；导出/导入 JSON；重置模板。
- **打印**：只输出纸张内容，按当前横竖版分页。
- 调试：`window.__paibanApi` 暴露 doc/selection/history 等。

## 版式参考

编辑器字号和分页规则参考了 `地理周报_第一期.html`：

- 正文 14px（黑体五号），行高 1.55；
- 提示框/概念框/逻辑链/易错/答题模板/要求 13px；
- 习题 11px，解析 10px；
- 章节标题 13px，编号 12px；
- 页脚 10px；
- 双栏、页脚页码 `— N / 总页数 —`。

## MCP（给 agent 用）

项目自带一个 stdio MCP，能直接操作排版编辑器：状态、DOM、控制台、截图、
执行页面 JS、切横竖版、清空存档、跑冒烟。

接入配置示例：

```json
{
  "mcpServers": {
    "paiban": {
      "command": "node",
      "args": ["tools/paiban-mcp/server.mjs"],
      "cwd": "/Users/gongyi/wenxiang/paiban"
    }
  }
}
```

工具列表与参数见 [`tools/paiban-mcp/README.md`](tools/paiban-mcp/README.md)。

## 已知限制
