# 地理时政周刊 · 排版编辑器

React 19 + Vite + TypeScript 的报纸/周刊排版工具。默认入口是**可视化排版编辑器**，
支持双栏 A4 横版/竖版、53 种可搜索组件、拖动避让、文字自动增高、跨页按行切割、
溢出自动翻页、全屏背景图、本地图片和打印/导出 PDF。

```bash
pnpm install
pnpm dev          # http://127.0.0.1:5173
pnpm build        # 生成可直接双击的单文件版
pnpm typecheck
pnpm smoke        # Playwright 回归（38 项）
pnpm mcp          # 项目 MCP（stdio）
```

## 打包成桌面应用（macOS / Windows）

打包用的是 Electron：主进程在 `127.0.0.1` 的随机端口起一个**只跑本机**的小服务
（静态 dist + `/@doc-import` + `/@imported` + `/@local`），窗口加载这个地址。
所以桌面版和 `pnpm dev` 走的是同一套代码，Word 解析、图片读写全在本机，不联网。

```bash
pnpm app                 # 直接在本机跑（先 pnpm build）
pnpm desktop:check       # 自动化体检：起窗口 → 导入 Word → 开打印预览 → 截图
pnpm dist:mac            # 出 dmg（arm64 + x64 两个）
pnpm dist:mac:arm        # 只出 Apple Silicon 的 dmg
pnpm dist:win:portable   # 出 Windows 免安装 zip（macOS 上也能打，不需要 Wine）
pnpm dist:win            # 出 Windows 安装版 exe（electron-builder --win，需要 Windows 或 Wine）
```

产物都在 `release/`：

| 文件 | 说明 |
| --- | --- |
| `地理周刊排版-<版本>-mac-arm64.dmg` | Apple Silicon（M 系列）Mac，双击挂载拖进「应用程序」 |
| `地理周刊排版-<版本>-mac-x64.dmg` | Intel Mac |
| `地理周刊排版-<版本>-win-x64-portable.zip` | Windows 免安装：解压后双击 `地理周刊排版.exe` |

几个必须知道的点：

- **没有开发者证书时是 ad-hoc 签名**（`scripts/sign-adhoc.cjs` 在 afterPack 里做）。
  本机能跑，但把 dmg 发到别的 Mac，首次打开要「右键 → 打开」，
  或者让对方执行 `xattr -dr com.apple.quarantine /Applications/地理周刊排版.app`。
  要彻底不报警需要 Apple 开发者 ID 证书 + 公证。
- **Windows 免安装包**是把官方 Electron 运行时和 `resources/app` 拼起来的，
  没有改 exe 图标/版本信息（那一步要 Wine）。想要带图标、带开始菜单的正式安装包，
  在 Windows 机器上跑 `pnpm dist:win`。
- **Windows 上导入 Word 需要本机有 Word / WPS / LibreOffice**：
  `tools/import/parse.mjs` 会按 `soffice → Word COM → WPS COM` 的顺序试着把
  `.doc/.docx` 转成 HTML（macOS 仍优先用系统自带 `textutil`，零依赖）。
  三个都没有时会返回明确的错误提示，让用户另存为 `.docx`。
- 存档（localStorage）、导入的图片放在 `userData`：
  macOS `~/Library/Application Support/地理周刊排版/`，Windows `%APPDATA%\地理周刊排版\`。
  菜单「帮助 → 打开存档目录」可以直接跳过去。
- 打包时如果 Electron 下载慢，设 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`
  并给 electron-builder 指一个项目目录**之外**的缓存：
  `ELECTRON_BUILDER_CACHE=/tmp/eb`（放在项目里会因为它自己的 `.js` 被 `"type":"module"` 当成 ESM 而报错）。

| `pnpm preview` | 预览构建产物，同样支持本地图片代理 |

> 另外加了全局错误兜底：坏存档/运行期异常会显示恢复面板，而不是白屏。

## 导入 Word 原稿（本机解析）

点工具栏「Word」按钮选一份 `.doc / .docx / .rtf` 原稿，编辑器会把整份文档解析成组件、替换当前版面。
浮层里先选「版式」（横版 / 竖版，默认跟随当前版面），再选文件。全程在本机完成，不上传任何服务器。

```
原稿 .doc
  ├─ textutil 转 HTML（macOS 自带）           tools/import/parse.mjs
  ├─ OLE 二进制里抽图片                        tools/import/ole.mjs + images.mjs
  ├─ 规则表：段落 → 组件变体                   tools/import/rules.mjs
  └─ 前端按栏装箱 → reflowDoc 自动分页         src/editor/importDoc.ts
```

**能自动识别的结构**：一级标题（`一、xxx` → 章节条）、二级标题（`1. xxx` → h3）、
正文段落、`>字段：` 标签段、逻辑链（3 个以上 `→` → chain）、名词解释（核心定义章节下的
`名词：解释` → concept-box）、易错项（易错章节或含「切忌/并非/杜绝」→ trap）、
答题模板（`【x模板】` + 条目 → tpl）、选择题（题干 + A/B/C/D + 答案 + 解析 → quiz）、
综合大题（`（1）…（6分）` + 标准答案 → quiz）、学习要求（→ req 编号）、姓名学号（→ name-row）。

**元信息**：页眉刊名/期号、页脚口号与「使用日期 · 编辑 · 核对」都从原稿正文里提取，
页码由编辑器自动生成。提取不到就用模板默认值。

**图片**：从 `Data` / `WordDocument` 流里按 PNG / JPEG / EMF 签名抽取，落到
`public/images/imported/`（7 天后自动清理），页面里通过 `/@imported/<文件名>` 读取——
不走 Vite 静态中间件，因为刚写入的文件第一次请求会被 SPA 兜底成 `index.html`，
浏览器拿到 200 却不是图片，版面里就会显示破图。宽高比 < 4 的第一张当作正文插图放在最前面，
其余只入库；抽不到就留占位框并在导入结果里提示。

**导入成横版还是竖版**：浮层里「版式」一行可选，默认跟随当前版面，也可以临时换。
选竖版不是「先排成横版再切成竖版」，而是**直接用竖版的纸张和栏宽装栏**——
量文字高度用的栏宽、装栏容量、图片上限全部按目标版式算，再交给 `reflowDoc` 收尾。
所以同一份原稿：横版 3 页、竖版 3 页但每页更满（栏更窄、页更高）。
`importToDoc(payload, { orientation: 'portrait' })`，返回里的 `orientation` 是实际采用的版式；
MCP 的 `paiban_import_word` 同样支持 `orientation` 参数。

**短条目合并 / 拆分**：「本期学习要求」「必考能力」「易错项」这类一条一句的短列表，
点「Word」后的浮层里可以选三种处理方式，选择会记住（`localStorage`）：

| 选项 | 行为 | 适合 |
| --- | --- | --- |
| 自动（默认） | 合并、拆分各排一遍，取页数最少、且列表没被分页切开的那个 | 一般情况 |
| 合并 | 整组（含上方小标题）合成一个组件 | 不想让列表被切开、想整块拖动 |
| 拆分 | 每一条都是独立组件 | 需要逐条微调样式/位置 |

合并只是把同层 HTML 直接拼接，**观感和拆分完全一致**（只少了组件之间的 4px 间距），
并且保留原始分片，所以两种形态随时可以互换。
实现上不是"少一页"的魔法：合并省下的间距 + 装栏尺度收紧（`loose` 留 10px 余量 /
`tight` 留 1px）共同决定页数，自动模式会两种都试。

**导入结果**用应用内通知弹窗展示（`Notice.tsx`，玻璃态卡片），不用浏览器原生 `alert`：
标题 + 段落/组件/页数三个数字 + 需要注意的条目，底部直接给「撤销导入」和「知道了」。
解析失败是红色错误态；`Esc`、✕、点遮罩都能关。
弹窗用 `createPortal` 挂到 `document.body`——工具栏带 `backdrop-filter`，会让 `position: fixed`
相对工具栏定位，直接渲染在工具栏里会被挤到视口外。

**规则在哪里改**：`tools/import/rules.mjs` 顶部的
`H3_KEYWORDS / TRAP_WORDS / NOTE_WORDS / CONCEPT_CTX / REQ_CTX / TRAP_CTX`，
以及字号分级常量 `SIZE_L1 / SIZE_L2`、短条目常量
`MERGE_VARIANTS / MERGE_MAX_CHARS / MERGE_MAX_ITEMS / MERGE_HEADING`。
改完用命令行验证，不用开浏览器：

```bash
pnpm import:debug ~/Desktop/docs/地理时政周刊一.doc        # 打印识别出的组件列表（含短条目组）
pnpm import:debug <doc> --split                          # 短条目按拆分输出
pnpm import:debug <doc> --json                            # 输出完整 JSON
pnpm import:verify <doc>                                  # 真实点一次导入，检查重叠/溢出并截图
pnpm import:verify <doc> --portrait                       # 同一个脚本，导入成竖版再验一遍
```

**三点局限，先说清楚**：

1. 下面这些内容原稿里没有，是排版时加的，导入只能给默认值或留空——
   报头副标题、①②③④ 编号、题号、✕ 符号、配图位置。导入产出是「90 分初稿」，不是成品。
2. 页数由内容决定。自动模式会试两种装栏尺度，通常能和手工排版的页数对齐
   （首期原稿：手工 3 页，导入也是 3 页）；仍差一页时可用「自动重排」或手动压缩。
3. 解析需要一个 Node 进程 + 一个系统转换器，**纯静态托管下用不了**。部署到服务器请看下一节。

## 部署到服务器（为什么放上去以后 Word 不能导入）

**Word 解析不是纯前端能力。** 页面点「Word」后走的是 `POST /@doc-import`，
接收方在 Node 侧（`tools/import/server-plugin.mjs`），它会：

1. 用系统转换器把 Word 转 HTML —— macOS `textutil` / LibreOffice `soffice` / Word COM / WPS COM
2. 从 OLE 二进制里抽图落盘
3. 过规则表 → 回一组元素给前端装箱

所以**把 `dist/` 的静态文件扔到 nginx / OSS / Pages → 那个端点不存在 → 导入必然失败**。
（这一层现在会在界面上说清楚：Word 按钮自动置灰，悬停显示怎么办。）

### 正确姿势：用 Node 服务托管（已自带）

```bash
pnpm build
pnpm serve:check                          # 先体检转换器在不在（不启动服务）
pnpm serve --host 0.0.0.0 --port 8080     # 静态 dist + Word 解析都在这一个进程里
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--host` | `127.0.0.1` | 要局域网/公网访问再写 `0.0.0.0`（服务本身没有任何鉴权，登录/HTTPS 请交给 nginx 反代） |
| `--port` | `5173` | 监听端口 |
| `--dist` | `dist` | 静态目录 |
| `--images-dir` | `var/imported` | 导入图片落盘位置。**别放 `dist/` 里**，重新构建会被覆盖；容器部署请挂持久卷 |
| `--no-local` | 开 | 关掉 `/@local` 磁盘代读。对外监听时**必须关**，否则等于开放服务器任意图片读取 |

### Linux 服务器要装一个转换器

```bash
apt install -y libreoffice-writer        # Debian / Ubuntu
yum install -y libreoffice-writer        # CentOS / RHEL
libreoffice --version                    # 有输出就是装好了
```

装完重启 `pnpm serve` 即可（不用重新 build）。macOS / Windows 桌面版走各自的转换链路，不用装。

> `.doc`（Word 97-2003 二进制）只有转换器能读，浏览器里纯 JS 解不了；
> `.docx` 理论可以前端解析，但这个项目的规则表依赖转换出来的 HTML 样式信号，`textutil`/LibreOffice 的
> 输出更稳定。所以服务器方案才是正解。

## 核心排版能力

### 1. 拖动避让：停 0.8s 才挤开其他组件

- 拖动的组件会临时置顶，不会被高层级的不透明块盖住。
- **拖动过程中只有被拖的组件在动**，其他内容不会被顶飞。指针停稳 0.8s（`DWELL_MS`，容差 3px 手抖）后，
  被压住的组件才沿拖动方向/最小穿透方向推开，可级联；被推到页底的组件会进入分页流程。
- 停住期间组件显示**蓝色虚线框**提示“再等一会儿就会让位”；一旦继续移动，让位会**自动回退**，不会留下位移。
- 松手时在落点落实一次推挤（并触发回流压缩），所以不会留下重叠。
- 锁定元素是实心障碍，拖不进去。
- 被推动的组件始终限制在版心/自身区域内，不会飞到页头、页脚下面躲起来。

### 2. 跨页移动 + 自动补齐（紧凑布局）

- 直接把组件拖到其他页面上松手，即可跨页移动；拖到最后一页下方会新建一页。
- 跨页拖动时源组件半透明、指针旁显示浮层预览，目标页有橙色虚线框和「松手移到第 N 页」提示。
- 松手后**原页自动补齐**：每栏从版心顶部紧凑重排，元素之间只保留 4px 间距，不再留下大洞。
- 右侧属性面板也可「移到第 N 页」，或使用「← 上一页 / 下一页 →」「移到该页」。
- 锁定元素不参与补齐移动，作为固定障碍保留原位。

### 3. 自动高度 + 按行切割 + 自动翻页

- 正文/内容框按真实内容自动增高，下方组件依次下推。
- 边打字边变高：双击进编辑后，**输入过程中框就跟着长高**（只改 DOM 高度，不写文档，避免丢光标），
  不必等退出编辑；退出编辑时再按真实高度写回文档。
- **手动锁过高度也照样长**：拖过上下手柄、或在属性面板输入过「高」的元素会变成「锁高」，
  此时只在**内容装不下**（真实高度 > 框高）时向上长高，**绝不自动缩回**——
  所以你手动调大的高度不会被测量改小，但文字永远不会被框裁掉。
- 超过页底的文字块会在**页底按整行切开**：
  - 上半段留在原组件；
  - 下半段生成一个新组件，接到下一栏/下一页；
  - 不会把一行字切成两半，也不会产生只有标点的小碎片（上下段至少 12 字）。
- 图片、分隔线等不可拆分的组件整块流动。

阅读顺序（横版双栏统一是「页内左栏 → 页内右栏 → 下一页左栏」，**第 1 页也遵循**）：

- 任意页（含第 1 页）：左栏溢出 → **本页右栏**；右栏溢出 → **下一页左栏**。
- 所以阅读顺序永远是单调的：页 1 左 → 页 1 右 → 页 2 左 → 页 2 右 → …
- 手动「下一页」也统一接到目标页左栏顶部。

### 4. 打印预览：点一下就到预览、彩色/黑白在弹窗里切

- 点工具栏打印按钮**直接用一次点击打开预览弹窗**，不再先弹「选彩色/黑白」的设置浮层。
- 预览是**居中的大弹窗**（类似系统打印预览），不是全屏：遮罩 + 圆角卡片，尺寸 `min(1280px, 94vw) × min(900px, 90vh)`。
- 弹窗内部：顶部标题条（纸张 · 配色 · 页数 + **彩色/黑白分段开关** + ✕）→ 可滚动的纸张区 → 底部「缩放 xx% · 取消 · 打印 / 保存 PDF」。
- 纸张按**整页可见**自动缩放（宽高都放得下，以 `zoom` 实现），所以一打开就看到完整一版；窗口变小会重新计算。
- 关闭方式：右上角 ✕、底部「取消」、点遮罩、按 `Esc`。
- 点「打印 / 保存 PDF」才打开系统打印对话框；打印时自动复位缩放并隐藏标题条/底栏，只输出纸张。
- 彩色 / 黑白切换**只作用于预览弹窗**（`body.is-bw` → `.ed-page { filter: grayscale }`），不把编辑器画布变灰，也不改变页数；打印输出跟随当前选择。
- 打印时自动隐藏工具栏、侧栏、选中框/控制点，但**关闭打印后编辑器的选中状态会保留**。
- 修复空白页：打印时把侧栏折叠按钮、画布内边距、非纸张宽度全部清零，并按 A4 宽度约束页面；回归会用 PDF 实际页数校验，3 页文档必须输出 3 页。

### 5. 表格与组件结构编辑

- 表格：新建为 **3×3 空白表**，不带示例内容，可一键「清空表格内容」。
- 右侧「表格结构」显示当前行×列，可改表头/单元格，直接 ＋行 / ＋列 / −行 / −列；新增行会**沿用上一行行高**。
- 选中表格后，表格内部会出现**列线 / 行线拖拽把手**：上下拖行线改行高，左右拖列线改相邻列宽，宽高随拖动实时更新。
- 其他复合组件（时间线、左右对比、卡片、徽章等）：选中后在「内部元素」里可改文字内容、复制、上移、下移、删除；结构变化后自动重排。
- **逻辑链**：专用节点编辑器，只填节点，节点之间自动生成 →；加节点自动补箭头，删节点自动收链。
- 任意组件底部的「HTML 源码 / 高级结构编辑」可以直接改内部 HTML，适合没有专用表单的组件。

### 6. 复合组件内部元素

- 选中报头、页眉、页脚、卡片等复合组件后，右侧出现「内部元素」列表，如报头的「期刊一 / 主标题 / 副标题」。
- 列表**竖排、一行一个**（占满面板宽度，列表超过 168px 自动滚动），名字再长也不会互相挤压。
- 点列表项，或先在画布上选中组件、再点内部文字，即可单独选中该内部元素（橙色虚线框）。
- 可单独改字体、字号、字重、字色、对齐、斜体/下划线；也可用方向键 1px / Shift 10px 调位置（内部元素不吃「交换」那套键位）。
- 内部元素变高时，外层组件框会自动长高；改完可点「重置此内部元素」。

**页眉 / 报头 / 页脚（锁定件）**：导入的文档会把这三件设成 `locked`，防止误拖把整页内容挤走。
锁定只禁止**拖动和改尺寸**，不影响其他操作：

- 单击可以选中，右侧属性面板照常出现（可改字体、字号、线宽、底色）；
- **双击可以直接改文字**（内容改动同步到所有页，页脚页码仍按页更新）；
- 初始模板里这三件默认不锁，可以自由拖动。

### 7. 底色 / 背景色

- 「底色」就是组件背景色，作用到组件内容表面，不是只改外层透明选区。
- 提示框、表格、页脚、卡片等内容组件内部自带白底，之前会盖住外层颜色；现已改为直接给内容表面着色。
- 支持预设色、透明、原生取色器自定义颜色；当前色块带蓝色选中圈。

### 8. 组件识别 + 方向键交换 / 微调

- 点选任意组件后，右侧属性栏标题显示组件中文名，例如「组件属性 · 正文」「组件属性 · 提示框」「组件属性 · 页脚」。
- **方向键 = 与相邻组件交换位置**（见下）；**Alt / Option + 方向键 = 移动 1px**，再加 Shift 为 **10px**。
- 微调不会触发自动补齐/重排，组件不会刚移动就被吸回原位；需要重新紧凑时点「立即重排」。
- 页眉/报头/页脚仍受页边区域约束：整宽页脚左右已贴边时，横向不会再移动，但纵向可以微调。

### 8.1 方向键与相邻组件交换位置

调换两个组件时不用再拖来拖去（拖动会推挤其他内容），直接按键换：

| 按键 | 行为 |
| --- | --- |
| `↑` / `↓` | 与**同一栏**内上方 / 下方最近的组件交换顺序 |
| `→` / `←` | 与同一行（纵向有重叠）右侧 / 左侧最近的组件交换，可跨栏 |
| `Alt+方向键` | 微调 1px（`Alt+Shift` 为 10px） |

实现要点：

- 只交换**阅读顺序上的位置**，不改变两者合起来占的垂直空间（`A.h + 间距 + B.h`），
  所以交换后总底边不变，**不会把下面的内容挤走，也不需要重排整页**。
- 高度不同也能换：高的一方换到上方时，矮的一方自动接到它下面，间距沿用原来的。
- 水平方向宽度不同时，交换后如果会越出版心就直接放弃（不会把组件挤到页外）。
- 找不到邻居（已在最上/最下、或该方向没有投影重叠的块）时按键无动作，**也不会写撤销历史**。
- 页眉/报头/页脚、全屏背景、区域框、锁定元素不参与交换。
- 选中了复合组件的**内部元素**时，方向键仍然只微调那个内部元素。

### 9. 线宽统一可调

- 选中组件后，右侧「外观 / 层级 → 线宽」可设 1/2/3/4/6/8px 或恢复默认。
- 作用于：页眉下划线、报头装饰线、章节下划线、页脚上边框、提示框/概念框/逻辑链/模板边框、表格边线、卡片/对比/材料/公式/目录/批注/二维码边框、三种分隔线、区域虚线框。
- 「分隔线」组件的线宽 = 组件高度，可直接用 1/2/3/4/6/8 按钮调粗细。
- 编辑器内页脚已改为正常文档流：选择框与页脚内容完全一致，不再出现“框在上面、内容在下面”的错位。

### 10. 53 种组件 + 动态常用 + 列表模板

- 标题/导读、文本、内容框、数据/图表/版式/装饰、其他，共 53 种。
- 新增 **报头**：放在页眉下方，包含期刊名、主标题、副标题，可继续用「内部元素」单独调字体/位置。
- 新增 **有序列表 / 无序列表**：右侧「列表模板」可在圆点/方块/对勾/箭头/卡片、数字/前导零/字母/罗马/中文/括号/大号数字/带圈数字等模板间切换，并增删改列表项。
- 组件库「常用」区新增 **页眉 / 页脚**：页眉自动落在页顶，页脚自动落在页底并更新页码，可改内容/字号/线宽。
- 页眉/页脚的**内容、字体、线宽、尺寸、内部元素、位置**在任意一页修改后会同步到所有页；页脚页码仍按页自动更新。
- 新增：副标题、三级标题、编号标题、英文小标、导语、金句、数据强调、图注、署名；
  选择器组、材料分析、知识卡片、考点清单、三种提示条；数据卡片、左右对比、时间线、表格、公式；
  本期导读、编者按、页边批注、二维码框、标签徽章、色块标题条、序号圆标、三种分隔线。
- **常用区是动态的**：不再预置固定清单；你实际点击/拖入过哪个组件，它就自动 push 到「常用」最前面；已经在常用里的组件保持原位置，不会重复 push。
- 常用最多 **12 个**：超过时踢掉最后一个，再 push 新的。记录保存在 localStorage。
- 画布选中某个组件时，组件库里对应的组件会高亮；项目里出现的任何变体都能在组件库找到对应项。
- 网格排列，默认每行 **4 个**，可在组件库右上角切换 **4 / 5 栏**；长名称使用短名 + 悬浮完整说明。
- 组件库顶部搜索框支持按名称/说明过滤。

### 11. 二维码框可更换图片

- 选中二维码框，右侧「二维码图片」可填 URL / `file://` / data URL，或点「选择二维码图片」上传本地图片。
- 二维码会渲染成真实 `<img>`，打印时不会因“背景图形”选项被漏掉。
- 右侧「扫码关注…」文字可双击组件直接改。

### 12. 模板库（本地优先）

- 内置「默认模板 · 现有布局」作为第一个模板，可直接复用。
- 「保存当前布局为模板」保存到 localStorage；模板包含页面、组件、图片（尽量内嵌为 data URL）。
- 模板卡片支持应用、分享、删除；分享下载 `.paiban.json` 文件，别人用「导入模板文件」即可使用。
- 所有模板、当前文档都存本机，不需要服务器；后续打包本地 App 时可直接沿用。

### 13. 玻璃态 UI

- 侧栏、格式栏、属性面板、打印浮层统一使用半透明玻璃态 + 背景模糊 + 圆角 + 柔和阴影。
- 画布使用柔和渐变背景，纸张圆角显示（打印时恢复直角）。
- 按钮、输入框、组件卡片、颜色块统一圆角和 hover 反馈。

### 14. A4 横版 / 竖版

- 工具栏「竖版 / 横版」或右侧「页面设置」一键切换，所有页统一方向。
- A4 物理尺寸按 96dpi 精确换算（297×210mm / 210×297mm）；版心固定：左右 12mm、页眉 10mm、页脚距底 16mm。
- 切换时重算双栏宽度，组件按栏重映射；文字重新测量、下推、翻页。
- 页眉 / 报头 / 页脚是页面固定件，移动范围限制在页边区域，不会改变正文版心，也不会把整页内容挤走。
- 页眉/报头也参与真实高度测量：字号变大时框会跟着长高，正文起点同步下移，不会出现“框小内容大”压住下方组件。
- 回归测试会同时检查“页眉/报头/页脚与正文重叠”和“组件框高度小于内容高度”。
- 如果旧存档已经被误拖成空白第一页，读取时会自动检测并重建分页；也可在右侧页面设置点「重建分页 / 修复空白页」。
- 页脚页码自动更新为「当前页 / 总页数」。
- 打印 `@page` 尺寸跟随当前方向。

### 15. 全屏背景图

- 组件库「其他 → 全屏背景」：铺满所有页、自动置底（`z = -100`）、不参与避让/分页。
- 新页自动继承背景；切换横竖版自动铺满新纸张。
- 选中图片后可在右侧「设为全屏背景」「应用到所有页」。
- 背景图也可以用透明度滑杆压暗，方便正文阅读。

### 16. 本地图片

- `public/images/` 里的图片：`/images/img1.png`（默认示意图已放入）。
- 网络图片：`https://...`。
- 本机图片：
  - 开发/预览：`file:///Users/xxx/img1.png` 或 `/Users/xxx/img1.png`，走 `/@local` 代理；
  - 单文件版（`file://`）：使用 `file://` 或相对路径直接读取；
  - 通过 http 打开时，本地路径无法被浏览器直接读取，推荐用「选择本地图片」内嵌成 data URL。

## 编辑器用法

- **改字**：双击文本块进入行内编辑；点空白/Esc 提交。
- **移动/缩放**：拖动移动，可拖到其他页/新页；8 个角点缩放；方向键与相邻组件换位，Alt+方向键微调（再按 Shift ×10）。
- **加组件**：左侧拖入或点击；新组件自动对齐左/右栏，重叠内容下推。
- **区域约束**：画布工具条「▭ 框选区域」；区域内元素拖动/缩放被钳制。
- **格式栏**：字体、字号、加粗/斜体/下划线/删除线、字色、高亮、对齐、行距、字距、列表。
- **页面**：新增/删除页、上一页/下一页、立即重排/修复版面。
- **存取**：自动存 localStorage；导出/导入 JSON；重置模板。
- **打印**：只输出纸张内容，按当前横竖版分页。
- 调试：`window.__paibanApi` 暴露 doc/selection/history 等。

## MCP（给 agent 用）

项目自带一个 stdio MCP，能直接操作排版编辑器：状态、DOM、控制台、截图、逐页截图、
执行页面 JS、切横竖版、清空存档、导入 Word 原稿、跑冒烟。

已注册到 `~/.workbuddy/mcp.json`（`PAIBAN_URL=http://127.0.0.1:5174/`）。
首次使用需要在 WorkBuddy 的「自定义连接器」里点「信任」才会生效。

两种接入模式，用环境变量切换：

| 变量 | 行为 |
| --- | --- |
| `PAIBAN_URL` | 自己起一个 Chromium 打开该地址。会清存档，拿到干净版面，**不影响你手动打开的窗口** |
| `PAIBAN_CDP` | 接管你已打开的 Chrome（`chromium.connectOverCDP`）。**不动你的存档、不重载页面** |

接管真实浏览器需要 Chrome 带远程调试端口启动：

```bash
# 先关掉所有 Chrome 窗口，再用这条命令打开（标签页可在菜单里恢复）
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --remote-debugging-port=9222 --user-data-dir="$HOME/.chrome-debug"
```

然后把 mcp.json 里的 `PAIBAN_URL` 换成 `"PAIBAN_CDP": "http://127.0.0.1:9222"`。

典型用法：

```
paiban_console                  # 先看有没有报错（含 404 / 请求失败）
paiban_import_word {path, merge?}   # 导入原稿；merge=auto|merge|split 控制短条目合并
paiban_pages_shot {prefix}      # 逐页截图，和成品 PDF 逐页对比
paiban_status                   # 页数、每页底部、页码、出界/重叠检查
paiban_eval {expression}        # 页面里执行 JS，可直接用 api
```

接入配置示例：


```json
{

    "paiban": {
      "command": "node",
      "args": ["tools/paiban-mcp/server.mjs"],
      "cwd": "/Users/gongyi/wenxiang/paiban"
```

## 已知限制

- 文字切割按“整行”切，复杂行内样式/列表会随 HTML 片段一起复制；极长单块会切成多段。
- 图片/分隔线等不可拆分元素只能整块翻页。
- 通过 http 托管时，浏览器安全策略不允许自动读取本机任意路径；请用「选择本地图片」内嵌。
- 预览 `#/preview` 仍是原始两页报纸版，不随编辑器文档实时变化；编辑器内打印使用当前文档。
